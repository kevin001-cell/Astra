# Astra Desktop 1.6.8

## 1.6.8 本地运行时自检修复

- 随包 llama-server 不再执行可能阻塞的 `--version` 命令。
- 随包运行时完成文件与 DLL 校验后，直接使用真实服务健康检查验证。
- 用户自行选择的外部运行时版本检查超时由 10 秒提高到 30 秒。

## 1.6.7 本地运行时依赖修复

- 随 llama.cpp 运行时附带 Microsoft VC++ x64 所需的三个运行库 DLL。
- 本地运行时自检会直接报告缺失的具体 DLL，并记录退出码和输出。
- 修复未安装 Visual C++ Redistributable 的 Windows 电脑无法启动本地模型的问题。

## 1.6.6 官方模型元数据修复

- 使用 Hugging Face 官方 LFS 指针中的完整 SHA256，修正 Qwen3 1.7B、4B、8B 校验值。
- 修正 Whisper Small 固定提交 ID，并同步官方文件大小。
- 保留校验失败的实际哈希日志，便于直接核对官方文件。

## 1.6.5 模型校验修复

- 修正 Qwen3 1.7B、4B、8B 官方 GGUF 文件的 SHA256。
- 模型下载地址固定到已验证的 Hugging Face 提交，避免上游 main 分支变化造成误报。
- 校验失败日志会记录预期值和实际值，方便诊断下载或代理缓存问题。

## 1.6.4 模型下载网络修复

- GGUF 与离线语音模型下载改用 Electron/Chromium 网络栈，更好地兼容 Windows 系统代理。
- 网络失败时区分代理、DNS 与证书问题，不再只显示 `fetch failed`。

Astra Desktop 是一个 Windows 桌面助手 MVP，提供透明置顶桌宠、基础离线对话、AI 接口连接、系统语音播报和白名单工具。

## 1.6.2 桌宠交互重构

- 将桌宠反馈划分为眼神光效、可操作气泡和完整功能界面三层，减少不必要的整窗打断。
- 右键桌宠或使用 `Shift + F10` 打开固定快捷轮盘，可进入对话、语音、截图、提醒、专注、鼠标穿透、迷你和隐藏模式。
- 拖动时显示提起、推进器、倾斜和高速反馈；放下时区分轻落地、快速落地和屏幕边缘停靠。

- 输入 `/` 显示固定本地快捷指令，只能触发现有白名单动作，不接受 Shell、PowerShell、脚本或任意命令行参数。

## 1.5.1 本地模型部署、流式对话与稳定性

- 首次进入本地智能中心时显示模型部署助手，并根据系统内存推荐轻量、均衡或质量档位。
- 内置固定可信模型清单，可下载三档 Qwen3 GGUF 和 Whisper Small；下载仅使用固定 HTTPS 地址与固定文件名。
- 支持下载进度、暂停、继续、取消、断点续传和 SHA256 校验，模型统一保存到文档目录的 `Astra\Models`。
- 显示模型协议、下载大小、预计内存和磁盘空间，并提供检查、打开目录和安全删除功能。
- 本地对话使用 SSE 流式显示，支持停止生成、新消息取消旧请求、首字延迟、生成速度和上下文占用。
- 启动前检查 GGUF 文件头、聊天模板、运行时状态和预计内存；端口冲突时自动选择本机备用端口。
- 模型启动超时根据文件大小动态调整，并显示加载、内存分配、模板诊断、预热和就绪阶段。
- 本地模型异常退出后最多自动恢复一次，不自动重复提交上一条问题；最近启动错误只保存诊断信息，不保存聊天正文。

## 1.4.0 本地智能能力

- 内置官方 `llama.cpp b10472` Windows x64 CPU 运行时，用户主动选择 GGUF 模型后可进行完全离线对话。
- 支持可选 mmproj GGUF，本地多模态模型可处理用户明确发送的图片。
- 内置官方 `whisper.cpp v1.9.2` Windows x64 CPU 运行时，用户主动选择 Whisper BIN 模型后可离线转写。
- 本地知识库仅索引用户主动导入的文本文件，不自动扫描硬盘。
- 工作、休闲、游戏、会议和睡眠情景模式只改变本地通知、语音、动画和窗口显示。
- 白名单工作流只能组合固定工具、可信应用、音量、专注、情景、窗口和摘要动作，不接受脚本或命令行。

## 构建

首次构建或修改音量助手后，先生成固定本地助手：

```powershell
& 'C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe' /nologo /target:exe /platform:anycpu /optimize+ /out:build\volume-helper.exe native\Astra.VolumeHelper.cs
```

```powershell
pnpm dist
```

构建结果位于 `dist`。Windows 安装包尚未进行商业代码签名，首次下载运行时可能出现 SmartScreen 提示。

## 安全边界

- 渲染进程关闭 Node.js 集成并启用上下文隔离和沙箱。
- 系统工具只能调用主进程中的固定白名单。
- 不接受模型生成的任意 Shell、PowerShell 或文件删除命令。
- API Key 不写入代码、安装包或明文配置。
- 聊天内容不会自动写入 `memory.json`，本地记忆最多保存 100 条。
- 主动助手默认关闭，计划数据仅写入本机 `planner.json`。
- 主动上下文只包含用户在计划中心明确创建的待办和提醒，不读取其他应用窗口。
- 陪伴数据仅写入本机 `companion.json`，可独立重置且不会删除记忆与计划。
- 桌宠拖动只允许移动现有主窗口，并始终限制在当前显示器工作区域内。
