# Astra Desktop 1.7.0 使用指南

Astra Desktop 是一款 Windows 中文桌面助手，支持桌宠互动、在线或本地对话、语音、图片、计划提醒、本地记忆、知识库和固定白名单电脑操作。

本指南适用于安装版和便携版。Astra 只会在你从固定可信清单选择模型并确认后下载文件；不会自动上传图片、录音、聊天正文或本地文件。

## 1. 安装与启动

### 安装版

运行 `Astra-Desktop-Setup-1.6.8-x64.exe`，按照安装程序提示选择安装目录。首次启动时 Windows SmartScreen 可能提示未知发布者，这是因为当前 EXE 尚未进行商业代码签名。

### 便携版

运行 `Astra-Desktop-Portable-1.6.8-x64.exe`。便携版不需要安装，但本地设置、记忆、计划和其他数据仍会保存在当前 Windows 用户的数据目录中。

### 首次启动

首次启动会显示权限和隐私说明。Astra 只有在你主动使用相关功能时才会请求麦克风、选择图片、导入知识文件或执行白名单工具。

## 2. 主界面按钮

| 按钮 | 功能 |
| --- | --- |
| `◌` | 切换透明迷你桌宠模式 |
| `◇` | 开启或关闭鼠标穿透 |
| `▣` | 打开计划与主动助手 |
| `◷` | 打开专注陪伴 |
| `♡` | 打开陪伴与成长中心 |
| `◈` | 打开本地记忆中心 |
| `◆` | 打开本地智能中心 |
| `⚙` | 打开 AI、语音、数据和安全设置 |
| `—` | 隐藏主窗口，继续在后台运行 |
| `×` | 关闭或退出窗口 |

主界面的浏览器、记事本、计算器、下载目录、应用和技能按钮均属于固定白名单入口。

### 桌宠三层交互

- **眼神层**：鼠标靠近、快速划过或技能状态变化时，通过视线、核心灯和短动画反馈，不弹出文字。
- **气泡层**：停留、提醒和技能反馈使用小气泡，可直接选择“开始对话”或“语音输入”。
- **完整层**：长对话、设置、计划、记忆、本地智能和陪伴管理继续使用完整界面。

### 右键快捷轮盘

右键桌宠可打开快捷轮盘；键盘用户可以先聚焦桌宠，再按 `Shift + F10`。轮盘只包含固定功能：完整对话、语音、截图、提醒、专注、鼠标穿透、迷你模式和完全隐藏，不接受模型生成的命令。

### 拖动和鼠标互动

- 提起桌宠时显示推进器和悬浮姿势。
- 快速拖动时显示紧张反馈，放下后区分轻落地和快速落地。
- 放到屏幕边缘时播放扶墙、观察或坐下反馈。
- 鼠标靠近时视线跟随，快速划过时受到轻微惊吓。
- 鼠标在桌宠附近停留时可显示低打扰气泡；在头部停留约 1.2 秒可触发摸头反馈，并带有冷却时间。
- 连续快速点击会触发防重复回应，避免无限播放动画或重复增加成长事件。

## 3. 文字对话

在底部输入框中输入内容，点击右侧发送按钮或按回车发送。输入框支持多行内容和以下快捷操作：

- `Enter`：发送。
- `Shift + Enter`：换行。
- `Esc`：优先停止当前生成，其次关闭快捷轮盘、命令建议或当前浮层。
- `↑` / `↓`：读取本次运行中最近发送的文字，不会持久保存到磁盘。
- 输入 `/`：显示固定本地快捷指令，例如 `/计算器`、`/截图`、`/提醒`、`/专注`、`/语音`、`/迷你` 和 `/设置`。
- `Ctrl + V`：剪贴板包含图片时先加入附件预览；只有点击发送后才会交给当前模型。

Astra 支持三种主要回答来源：

- **在线 AI**：使用你在设置中填写的兼容 `/chat/completions` 服务。
- **本地 AI**：使用本机 GGUF 模型，不需要 API Key。
- **基础规则**：没有在线服务和本地模型时，仍可处理部分固定指令和简单回答。

如果希望完全不使用 API，请在本地智能中心将“对话后端”设置为“仅本地”。

### 联网搜索问答

联网搜索默认关闭，需要先在 `设置 → 联网搜索` 中开启并配置搜索服务的 API Key（仅加密保存在本机）。开启后有两种触发方式：

- 点击输入栏的 🌐 按钮：仅对本条消息联网，开关状态会被记住。
- 消息中包含“搜索”“搜一下”“查一下”等关键词时自动触发。

触发后 Astra 会先调用搜索服务，把前 5 条结果（每条约 300 字摘要）交给当前模型（本地或在线均可）归纳回答，并在回答末尾自动追加来源链接。搜索结果只注入文本摘要，不会抓取网页正文；搜索失败或超时会直接提示原因并降级为普通回答，不会阻断对话。

目前支持两家固定服务商：**博查**（国内可直连，付费）和 **Tavily**（有免费额度，通常需要代理）。不使用模型生成的网址发起请求，也不会保存搜索内容。

## 4. 16GB 电脑部署本地对话

安装包已经包含 `llama-server.exe`，但不直接捆绑大模型权重。1.5.1 可以通过“模型部署助手”从固定可信清单下载并自动配置模型，也可以继续手动选择已有 `.gguf` 文件。

### 推荐配置

对于 16GB 内存电脑，建议从以下配置开始：

- 模型规模：3B–4B。
- 量化格式：Q4，优先选择名称包含 `Q4_K_M` 的文件。
- 示例文件：`Qwen3-4B-Q4_K_M.gguf`。
- 性能档位：均衡模式。
- CPU 线程：先使用 `4`，速度较慢时可尝试 `6` 或 `8`。
- GPU 层数：内置运行时为 CPU 版，保持 `0`。

只需要下载一个完整的 `.gguf` 文件，不要下载整个模型仓库，也不要选择名称包含 Embedding 的向量模型。

### 使用模型部署助手

1. 点击顶部 `◆`，首次进入时会自动显示模型部署助手。
2. Astra 根据系统内存标记推荐档位；16GB 内存默认推荐均衡模式。
3. 选择“均衡 · Qwen3 4B Q4_K_M”，阅读大小、预计内存和协议说明。
4. 点击下载并确认，下载过程中可以暂停、继续或取消。
5. 下载完成后 Astra 自动计算 SHA256；校验通过后才会把文件设置为本地模型。
6. 下载模型统一保存在 Windows 文档目录下的 `Astra\Models`。
7. 可使用“检查当前模型”“打开模型目录”或模型卡片上的“删除”按钮管理文件。

可信清单只允许固定 `.gguf` 和 `ggml-*.bin` 文件，不允许脚本、程序或用户输入下载地址。

### 手动模型保存位置

建议创建固定目录，例如：

```text
D:\AstraModels\Qwen3-4B-Q4_K_M.gguf
```

也可以放在：

```text
C:\Users\你的用户名\Documents\AstraModels\模型名称.gguf
```

模型配置完成后不要移动或改名，否则 Astra 下次启动时会找不到模型。

### 手动配置步骤

1. 打开完整对话界面。
2. 点击顶部 `◆`，进入“本地智能中心”。
3. 勾选“启用本地模型”。
4. 将“对话后端”选择为“仅本地”。
5. 将“性能档位”选择为“均衡模式”。
6. CPU 线程填写 `4`，GPU 层数填写 `0`。
7. “运行时”通常会自动显示安装包内置的 `llama-server.exe`，正常情况下不需要手动选择。
8. 点击“选择模型”，选择下载好的 `.gguf` 文件。
9. 暂时不使用图片理解时，mmproj 一栏保持为空。
10. 点击“保存配置”。
11. 点击“启动本地模型”。

状态显示“运行中”或“已配置”后，关闭本地智能中心即可直接对话。首次载入模型可能需要几十秒。

本地服务只监听 `127.0.0.1`。默认从端口 `39271` 开始，发生占用时会自动选择安全备用端口。模型空闲约 10 分钟后会自动停止以释放内存，下次发送消息时会自动重新启动。

本地回答会边生成边显示。回答下方可显示首字延迟、生成速度和上下文占用；生成期间可以点击红色停止按钮。直接发送新消息时，Astra 会先取消旧请求，并且不会自动重复提交旧问题。

## 5. 在线 AI 配置

点击顶部 `⚙` 打开设置，填写：

- API 地址：兼容 OpenAI `/chat/completions` 的服务地址。
- 模型名称：服务商提供的模型标识。
- API Key：只在本机使用 Windows `safeStorage` 加密保存。

如果只使用本地模型，以上项目可以留空。

“自动选择”模式会在在线 AI 可用时优先使用在线服务，在线服务不可用时回退本地模型。希望始终离线时必须选择“仅本地”。

## 6. 图片对话

点击输入框左侧的 `＋` 选择图片，也可以粘贴或拖入图片。发送前可以预览和删除。

图片只有在你点击发送后才会交给当前选择的模型，Astra 不会自动截图或自动上传图片。

本地图片理解需要同时满足：

1. 使用支持视觉能力的多模态 GGUF 模型。
2. 选择与该模型严格匹配的 mmproj GGUF 文件。
3. 在本地智能中心同时配置模型和 mmproj。

普通文字 GGUF 无法通过单独添加 mmproj 自动变成视觉模型。模型与 mmproj 不匹配时可能启动失败或无法识别图片。

## 7. 按住说话

按住输入框左侧的麦克风按钮开始说话，松开后进行识别。检测到约 1.2 秒静音时也会停止，单次录音最长 30 秒。

识别顺序通常为：

1. 已配置的在线 `/audio/transcriptions`。
2. 已启用的本地 Whisper。
3. Windows 系统语音识别兜底。

用户开始说话时，Astra 会停止当前语音播报，避免同时说话。

## 8. 完全离线语音

安装包已经包含 `whisper-cli.exe`，但不包含 Whisper 模型文件。

配置方法：

1. 准备 whisper.cpp 格式的 `ggml-*.bin` 模型。
2. 点击顶部 `◆` 打开本地智能中心。
3. 勾选“启用本地语音识别”。
4. 运行时通常会自动选择内置的 `whisper-cli.exe`。
5. 点击“选择模型”，选择 `ggml-*.bin` 文件。
6. 点击“保存离线语音配置”。

16GB 内存电脑可以优先选择较小的 base 或 small 级别模型。模型越大，识别通常越准确，但启动时间和 CPU 占用也会增加。

录音只在内存中处理，不会自动保存为音频文件。

## 9. 实时语音

设置中可以开启实时语音功能。实时语音需要兼容的在线 Realtime 服务和麦克风权限，支持流式字幕、自然打断、语义 VAD 和断线重连。

实时语音不可用时，可以继续使用“按住说话”模式。没有在线服务时，实时双向语音不可用，但按住说话可以配合本地 Whisper 和本地 GGUF 对话使用。

语音技能桥接会在本地识别“打开计算器”等白名单命令，并要求你说“确认”后才执行。模型不能直接生成电脑命令。

## 10. 本地知识库

点击 `◆` 打开本地智能中心，在“本地知识库”区域点击“导入”。

支持主动导入：

- TXT
- Markdown
- CSV
- JSON
- LOG

Astra 不会扫描整个硬盘，只处理你明确选择的文件。导入后可以使用搜索框测试检索结果。

删除知识索引不会删除原文件。移动或修改原文件不会自动重新索引，需要重新导入。

提问时，本地检索会将长度受限的相关片段交给当前对话模型进行回答。即使没有 AI 模型，Astra 也可以显示找到的部分原文片段。

## 11. 本地记忆与人格

点击顶部 `◈` 打开记忆中心，可以设置称呼、人格和回答风格。

支持的自然语言示例：

```text
记住我喜欢蓝色
以后叫我托尼
你记得什么
忘记蓝色
忘记全部记忆
打开记忆中心
```

聊天内容不会自动保存。只有明确说“记住……”或在记忆中心手动添加时才会写入本地记忆。

密码、API Key、令牌、验证码、银行卡、身份证和私钥等敏感信息会被拒绝保存。最多保存 100 条记忆。

## 12. 计划、提醒和主动助手

点击顶部 `▣` 打开计划中心，可以添加、编辑、完成和删除待办事项，并创建具体日期时间的提醒。

聊天示例：

```text
提醒我 5 分钟后喝水
```

主动助手默认关闭。开启后可以使用：

- 启动问候。
- 每日摘要。
- 当前时间段和待办上下文。
- 免打扰时间。

到期提醒遇到免打扰时间会延后，而不是直接丢弃。主动助手只读取你在 Astra 中创建的本地计划，不读取其他应用内容。

## 13. 专注陪伴

点击顶部 `◷` 打开专注中心，可以启动番茄钟、休息计时和喝水提醒。

专注期间桌宠会减少无关动作和气泡，完成后播放简短庆祝反馈。专注历史只保存在本机，可以随时清空。

## 14. 情景模式

点击 `◆` 打开本地智能中心，可以切换：

- 普通
- 工作
- 休闲
- 游戏
- 会议
- 睡眠

情景模式只改变 Astra 自身的通知、语音、动画、主动气泡和显示方式，不读取其他应用窗口正文。

可以开启按本地时间自动切换。睡眠等时间规则支持跨午夜运行。

## 15. 白名单工作流

白名单工作流可以把多个固定动作组合起来，例如：

```text
开始工作：切换工作模式 → 打开 VS Code → 开始 25 分钟专注 → 显示今日摘要
```

工作流只能使用 Astra 提供的固定动作：

- 打开固定系统工具。
- 打开用户添加的可信应用。
- 设置固定音量。
- 开始专注。
- 切换情景模式。
- 切换完整、迷你或隐藏模式。
- 显示本地摘要。

工作流不允许 Shell、PowerShell、脚本、文件删除或任意命令行参数。建议保留“执行前确认”。

## 16. 固定白名单电脑操作

可以直接输入：

```text
打开浏览器
打开记事本
打开计算器
打开下载目录
打开 VS Code
截图
系统静音
取消静音
音量设置为 30%
音量大一点
音量小一点
```

文件搜索只允许桌面、文档和下载目录，不允许模型指定任意磁盘路径。

在设置的“应用白名单”中，可以自动检测微信、QQ 和 VS Code，也可以通过文件选择器添加其他可信 EXE。Astra 不接受模型生成的程序参数。

## 17. 迷你桌宠与后台模式

点击顶部 `◌` 切换透明迷你桌宠。双击迷你桌宠可恢复完整对话界面。

支持三种状态：

- 迷你桌宠显示。
- 完全隐藏并在托盘后台运行。
- 鼠标穿透。

如果找不到窗口，可以使用：

```text
Ctrl + Shift + Space
```

也可以右键系统托盘中的 Astra 图标，选择“显示并恢复操作”。系统还会保留紧急恢复快捷键。

鼠标穿透开启后约 20 秒会自动恢复，避免窗口永久无法点击。恢复时会恢复原来的主窗口，不会新建替代窗口。

## 18. 陪伴与外观

点击顶部 `♡` 打开陪伴中心，可以管理：

- 待机动作频率。
- 点击、拖动和边缘互动。
- 低性能模式。
- 陪伴值和称呼变化。
- 互动收藏册。
- 可关闭的成就系统。
- 红金、蓝银、黑紫等原创机甲配色和装扮。

陪伴系统只保存事件类型、次数和解锁时间，不保存聊天正文、语音内容或其他应用窗口内容。

## 19. 数据备份、恢复与清除

点击 `⚙` 打开设置，在“本地数据管理”中可以：

- 导出备份。
- 恢复备份。
- 完全清除本地数据。

备份包含设置、记忆、计划、提醒、知识索引、陪伴、专注、情景和工作流等本地数据，但不包含 API Key。

恢复和完全清除都需要用户主动操作。建议升级或更换电脑前先导出备份。

## 20. 更新与安全模式

Astra 不会自动下载或安装更新。只有配置 HTTPS 更新清单并手动点击“检查更新”后才会查询版本，下载和安装仍需用户确认。

如果遇到透明窗口、显卡或启动异常，可以在诊断区域使用安全模式。安全模式会关闭硬件加速、透明效果、置顶和鼠标穿透，方便恢复设置和导出诊断报告。

## 21. 常见问题

### 本地模型提示“尚未配置”

确认已经勾选“启用本地模型”，并选择有效的 `.gguf` 文件。模型移动或改名后需要重新选择。

### 本地模型启动超时

- 换用更小的 3B–4B Q4 模型。
- 关闭占用大量内存的软件。
- CPU 线程恢复为 `4`。
- GPU 层数恢复为 `0`。
- 检查是否有其他 `llama-server` 占用本地端口。

### 本地回复很慢

CPU 推理速度取决于处理器和模型大小。16GB 电脑建议先使用 3B–4B Q4 模型和均衡模式。不要一开始使用 7B–8B 高精度量化模型。

### 发送图片后提示需要 mmproj

当前选择的是本地后端，但没有配置匹配的视觉投影文件。普通文字聊天可以清空图片后继续；图片理解需要多模态模型和对应 mmproj。

### 按住麦克风没有文字

检查 Windows 麦克风权限，并确认在线转写、本地 Whisper 或系统语音识别至少有一种可用。

### 切换迷你模式后无法恢复

双击迷你桌宠，或按 `Ctrl + Shift + Space`，也可以通过托盘“显示并恢复操作”。

### Windows 提示未知发布者

当前版本未进行商业代码签名，SmartScreen 可能显示未知发布者。请只使用项目发布目录中的文件，并使用随附 SHA256 文件核对完整性。

## 22. 隐私与安全边界

- 不自动保存聊天到本地记忆。
- 不自动截图或上传图片。
- 录音只在内存中处理。
- 不扫描整个硬盘。
- 不读取未授权窗口标题、代码或正文。
- 不允许模型生成 Shell、PowerShell 或任意命令行参数。
- 电脑操作只使用固定白名单和声明式工作流。
- API Key 使用 Windows `safeStorage` 加密。
- 所有主动功能均可关闭，本地数据可以导出或完全清除。

## 23. 推荐的首次配置顺序

1. 启动 Astra，阅读首次权限说明。
2. 测试迷你模式和恢复快捷键。
3. 根据需要配置在线 AI，或部署本地 GGUF 模型。
4. 需要语音时再配置在线转写或本地 Whisper。
5. 设置称呼、人格和回答风格。
6. 创建一条测试提醒和一个待办。
7. 主动导入少量知识文件并测试搜索。
8. 配置可信应用白名单。
9. 创建一个保留执行前确认的工作流。
10. 完成配置后导出一次本地数据备份。
